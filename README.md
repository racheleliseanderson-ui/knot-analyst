Upgrade Knot Intelligence (Hook the Horizon) into a high-end, precise decision + diagnosis instrument for fishing connections while strictly preserving its core philosophy.

### Core Philosophy (do not break)

- This is a personal decision and diagnosis tool — not a knot library, not a 66-profile browser, and not a “how to tie everything” encyclopedia

- You bring the job and the problem; the mechanical model answers with constraints, field fit, and retie guidance

- Invalid options never score

- Diagnose is symptom-first, then connection + materials refine causes — still not a library filter

- Fail-closed on unsuitable recommendations

- Field-ready and honest

### Intelligence Upgrades

Make the mechanical model significantly smarter and more useful:

**Decide mode**

- Strengthen evaluation of connection type + materials + field conditions so the recommended knot better reflects real constraints (geometry, tie-ability under the stated conditions, retie frequency, system fit)

- Surface clear trade-offs when constraints conflict (e.g. maximum strength vs easy retie in cold wind)

- Improve guidance on why a knot is preferred and what conditions would change the recommendation

- Generate a clean “Knot Decision Card” with the recommendation, key reasons, and retie notes

**Diagnose mode**

- Improve symptom → likely failure modes → material/connection contribution → recommended checks → retie guidance

- Make the handoff from Diagnose → Decide seamless, carrying full context

- Better distinction between user error, material mismatch, and knot geometry issues

- Support realistic scenario starters (braid to fluoro, cold wind, free-swinging bait, jig under pressure, etc.) that load useful defaults

### Visual Design (High-End)

Elevate the current clean interface into a refined, high-end technical instrument:

- Aesthetic: Precision tool meets calm field instrument. Soft refined base (light or deep), excellent typography hierarchy, generous purposeful spacing, progressive disclosure

- Decide and Diagnose modes should feel distinct but part of one coherent system

- Constraint feedback and elimination of invalid options should be visually clear and elegant

- Beautiful empty states and a premium printable Decision / Diagnosis Card

### Workflow Upgrades

Make the experience smoother and more valuable:

- Improve the flow from job/problem input → recommendation or diagnosis → actionable next step

- Make scenario starters one-tap and immediately useful

- Keep the Diagnose → Decide handoff frictionless while preserving full context

- Make the output something an angler would actually use on the water or at the bench

### Tone & Voice

Keep the precise, mechanical, slightly dry field voice. Avoid tutorial fluff or generic knot advice. The tool should feel like a sharp, trustworthy connection analyst that respects real conditions and constraints.
